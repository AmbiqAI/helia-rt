# Security policy

## Reporting a vulnerability

Report a suspected security vulnerability in heliaRT privately, by email to
[support.aitg@ambiq.com](mailto:support.aitg@ambiq.com). Do not open a public
issue, pull request or discussion for it.

Include what you can of:

- the affected heliaRT release or commit;
- the target, toolchain and build configuration;
- steps or a model and input that reproduce the problem;
- the impact you expect.

GitHub private vulnerability reporting is the preferred channel once it is
enabled for this repository. When the **Report a vulnerability** button
appears under the repository's **Security** tab, use it instead of email.

## Supported versions

The [support policy](https://ambiqai.github.io/helia-rt/guide/maintenance/support/)
lists the releases that receive security fixes and for how long.

Ordinary bugs and integration questions go to
[GitHub issues](https://github.com/AmbiqAI/helia-rt/issues/new/choose).
